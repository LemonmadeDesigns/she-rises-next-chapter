# She Rises - Safe Haven for Empowerment

**Empowering women to rebuild their lives with dignity and hope.**

A modern, responsive website for She Rises, a nonprofit organization providing transitional housing, employment readiness, and mentoring support for women transitioning out of incarceration, homelessness, or unsafe situations.

## 🚀 Live Site

**Production**: [https://lemonmadedesigns.github.io/she-rises-next-chapter/](https://lemonmadedesigns.github.io/she-rises-next-chapter/)

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🏗️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI + shadcn/ui
- **Backend**: Supabase
- **Payments**: Stripe
- **Deployment**: GitHub Pages
- **Authentication**: Supabase Auth
